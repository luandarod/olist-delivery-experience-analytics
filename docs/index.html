Pipeline architecture

The repository now behaves like a small analytical product: raw ingestion, order mart generation, dashboard-facing exports, and validation of the output contract.

1. Raw ingestion
Reads Olist CSV files from `data/raw/` with a reproducible entry point.
2. Order-experience mart
Joins orders, items, payments, customers, sellers, and reviews into one business unit.
3. Descriptive serving layer
Exports route, category, payment, executive, and monthly analytical summaries.
4. ML validation layer
Adds feature importance, confusion, threshold, and calibration outputs.
5. Dashboard contract tests
Guards the artifacts that the static site actually consumes.
